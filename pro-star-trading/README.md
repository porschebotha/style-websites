# Pro-Star Trading website

Static one-page site (HTML, CSS, JavaScript) for Pro-Star Trading, Supplier of Promotional Products.

## Files
- `index.html`: all page content (Home, Shop by Category grid, Contact, footer)
- `css/styles.css`: styles, colours (CSS variables at the top), animations and responsive rules
- `js/main.js`: mobile menu, sticky nav, scroll fade-ins, active-link highlighting
- `assets/favicon.svg`: star favicon

## Hosting
No build step. Upload the whole `pro-star-trading` folder to any static host
(Netlify, GitHub Pages, cPanel `public_html`, etc.) or open `index.html` in a browser.

## Editing
- Colours: change the variables in `:root` at the top of `css/styles.css`.
- Contact details: search `index.html` for `083 356 4891` / `admin@prostartrading.co.za`.
- Product links: all category cards point to https://promoafrica.com.
